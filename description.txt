The Avaritia Terraria Mod is an end-game-focused add‑on for Terraria, 
inspired by the famous Minecraft mod Avaritia. 
It currently adds numerous high-powered items, 
special crafting stations and unique mechanics adapted from the original mod, 
such as singularity compression systems and infinity-tier gear.
The mod code is currently open source on Github under the MIT license.
